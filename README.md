# ShopLedger

ShopLedger is a hybrid inventory management and online store application designed for small and medium-sized businesses.

## Features

- Inventory Management
- Sales Tracking
- Customer Management
- Supplier Management
- Analytics Dashboard
- Online Store
- Low Stock Alerts
- PDF & Excel Reports
- JWT Authentication
- Barcode & QR Code Support
- Hybrid Mobile Application

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Chart.js
- jsPDF
- SheetJS
- Capacitor
